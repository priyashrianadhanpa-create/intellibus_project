INTELLIBUS AI PLATFORM

Comprehensive Technical Documentation, Architecture Flowchart & Security Overview

1. Executive Project Overview

IntelliBus AI is an enterprise-grade campus transportation intelligence system built to deliver sub-second vehicle telemetry, AI-driven arrival countdowns (ETA), Dijkstra shortest-path route optimization, automated stop geofence detection, driver safety monitoring, digital QR boarding validation, and role-based operational dashboards.

2. System Architecture & Interactive Data Flowchart

The architecture operates on an asynchronous reactive micro-event pipeline. Telemetry generated by driver hardware GPS sensors or multi-bus simulators streams over low-latency WebSockets to FastAPI backend handlers, which process stop geofencing, update machine learning algorithms, and broadcast coordinate updates to listening React Leaflet maps.

4. Security Architecture & Status

  • Authentication Standard: OAuth2 JSON Web Token (JWT) using HS256 algorithm and 7-day token expiration.
  • Password Hashing: PBKDF2-HMAC-SHA256 with 100,000 iterations and dedicated salt key.
  • Role-Based Access Control (RBAC): Enforced at both FastAPI dependency levels (backend) and React Router protected route wrappers.
  • CORS & Request Security: Configured middleware headers preventing cross-site scripting (XSS) and unauthorized cross-origin requests.
