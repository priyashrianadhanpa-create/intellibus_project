# 📲 IntelliBus AI - Mobile App (Expo Go)

This module provides a native mobile application built with **React Native** and **Expo**, designed for mobile phones (iOS & Android) via **Expo Go**, as well as tablets, laptops, and desktop computers.

---

## 🚀 How to Run with Expo Go on Mobile Phones & Tablets

### Prerequisites
1. Download the **Expo Go** app on your phone:
   - **Android**: Search "Expo Go" on Google Play Store.
   - **iOS**: Search "Expo Go" on Apple App Store.
2. Connect your mobile phone and development machine to the same Wi-Fi network.

### Launching Expo Dev Server
Navigate to the `mobile` directory in your terminal and run:

```bash
cd mobile
npx expo start
```

### Scanning the QR Code
1. A QR code will display in your terminal and browser window.
2. Open the **Expo Go** app on your mobile phone:
   - **Android**: Tap **"Scan QR Code"** inside Expo Go and point your camera at the QR code.
   - **iOS**: Open your default **Camera App** and scan the QR code.
3. The IFET Campus Transit app will instantly compile and launch on your phone!

---

## 🖥️ Cross-Device & Web Browsers

You can also run the mobile app directly on your web browser:

```bash
cd mobile
npx expo start --web
```
